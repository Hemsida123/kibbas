# Kibbas Snickarservice

27 färdiga HTML-sidor med lokala bilder och originalets logotyp. Ingen installation eller byggprocess krävs.

## GitHub Pages
Packa upp ZIP-filen och lägg innehållet i mappen kibbas-github i repots rot. Aktivera GitHub Pages från huvudgrenen och rotmappen. Länkar och bilder fungerar även med reponamn i adressen.

## Innehåll
- Fullstor hero med en altan från Kibbas referensurval.
- Nio tjänstesidor med bildgallerier och en filtrerbar referensöversikt.
- Åtta kontaktpersoner med raka, enhetliga originalporträtt.
- Second Chance med sex produktpresentationer och filter.
- Om oss, jobb, samarbeten, kvalitet och miljö, offert och integritet.

Offertformuläret öppnar ett mejlutkast i besökarens egen e-postapp. Besökaren måste själv skicka det där och bifoga eventuella bilder. Länk till företagets ordinarie offertformulär med filuppladdning finns också.

Produktpriserna är ett urval från kibbas.se kontrollerat 17 november 2026. Aktuellt skick, pris och tillgänglighet ska bekräftas av företaget. Inga produkter reserveras eller köps på denna webbversion. Länkar till originalannonser finns på produktsidorna.

Bilder och fakta kommer från kibbas.se. Inga recensioner, projektnamn eller kunder har hittats på. Företagets logotyp är bevarad. Arbets- och projektbilder används i rätt sammanhang.

Ändra innehåll i respektive HTML-fil. style.css styr utseendet och script.js sköter meny, filter, galleri och mejlutkast. Fontlicens: assets/FONT-LICENSE.txt.
